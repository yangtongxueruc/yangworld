# Yangworld — 微缩牧场互动小游戏

基于 Three.js 构建的治愈系微缩牧场 3D 交互页面，包含小羊生态、金渐层猫互动、河中游鱼、木拱桥、礁石、红顶农舍与羊圈、天气切换及多项隐藏彩蛋。

## 嵌入个人网站

发布到 GitHub Pages 后，可在个人网站中使用 `?pure=1` 隐藏右上角演示按钮，实现纯净全屏嵌入：

```html
<iframe
  src="https://<你的GitHub用户名>.github.io/yangworld/?pure=1"
  style="width: 100%; height: 600px; border: 0; border-radius: 16px;"
  loading="lazy"
></iframe>
```
